# Fumaça no Escapamento BR - Plugin (opcional)

Plugin para o mod **Fumaça no Escapamento BR** do American Truck Simulator.

O mod da Oficina Steam já coloca a fumaça escura no escapamento. Este plugin faz a fumaça seguir o motor:

Motor desligado: sem fumaça.  
Marcha lenta: fumaça leve.  
Acelerando fundo: fumaça bem mais densa.

## Download

Baixe o **Fumaca_Escapamento_Plugin.zip** na página de [Releases](https://github.com/vinealme/fumaca-escapamento-ats/releases/latest).

## Como instalar

Passo 1: feche o jogo.  
Passo 2: na Steam, botão direito no American Truck Simulator > Gerenciar > Ver arquivos locais.  
Passo 3: entre em `bin\win_x64` e crie a pasta `plugins` se ela não existir.  
Passo 4: copie o `fumaca_motor.dll` para dentro de `bin\win_x64\plugins`.  
Passo 5: abra o jogo e clique OK no aviso de plugin de telemetria (SDK).  
Passo 6: na oficina do jogo, coloque Acessórios > Escapamento > "Escapamento com Fumaca".

## Como remover

Apague o `fumaca_motor.dll` da pasta `plugins`.

## Observações

Só funciona no modo single player (não no Convoy). Funciona junto com outros plugins de telemetria.
